# EasyBuy — Pakistan-first online store builder

Shopify-style store builder for Pakistani sellers. COD-first, WhatsApp orders,
Roman Urdu UI, multi-currency international selling.

## Quick start

### 1. Supabase setup
1. Create a project at https://supabase.com
2. SQL Editor → New query → paste `schema.sql` → **Run**
3. New query → paste `schema_v6_all.sql` → **Run**

### 2. Config
```bash
cp config.example.js config.js
